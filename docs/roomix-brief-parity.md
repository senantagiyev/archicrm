# Roomix «Премиум бриф» — tam struktur (1:1 mənbə)

Canlı saytdan (roomix.space, dizayner hesabının «режим просмотра» rejimi) çıxarılıb.
`database/seeders/brief/bank.php` məhz bu sənədə görə qurulur — hər sual, hər variant,
hər qrup başlığı burada var. Dəyişiklik edəndə əvvəlcə BU faylı yenilə.

İşarələr:
- `[IMG]` — variantın özü foto kartdır (A patterni, `image_multiselect` / `image_select`).
- `[GAL]` — variant mətndir, yanındakı ikon nümunə qalereyasını modalda açır (B patterni, `inspire => true`).
- `*` — məcburi sahə.

Roomix qalereya şəkilləri: `https://api.roomix.space/storage/v1/object/public/brief-gallery/<qalereya_açarı>/…webp`
(məs. `styles_neoclassic`, `styles_art_deco`). Bu şəkillər Roomix-in müəllif hüququ altındadır —
Archi-də eyni **struktur** qurulur, şəkilləri isə admin paneldən (Sistem → Brif şəkilləri) yükləmək lazımdır.

Bölmə sırası (9):
`about_you` · `object` · `procurement` · `aesthetics` · `finish_materials` · `lighting` · `rooms` · `engineering` · `contacts`
